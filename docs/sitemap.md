# Sitemap — Café Aroma (E1)

```text
Início (index.html)
├── Menu (menu.html)
└── A nossa história (historia.html)

Todas as páginas incluem navegação para as outras duas páginas.
```

## Objetivo de cada página
- **Início:** apresentar a cafetaria e encaminhar visitantes para o menu.
- **Menu:** mostrar exemplos de produtos e preços numa tabela acessível.
- **A nossa história:** explicar o conceito e apresentar imagens do ambiente.

Este mapa representa a estrutura inicial da E1. As páginas de contacto, artigo e declaração de acessibilidade serão acrescentadas em entregas posteriores.

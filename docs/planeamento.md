# Documento de Planeamento — Café Aroma

**Unidade Curricular:** Programação Web - Cliente  
**Projeto:** Sítio Web para o "Café Aroma"  
**Entrega:** E2 — Planeamento e Formulários  

---

## 1. Visão Geral do Projeto
O objetivo principal é conceber, desenvolver e publicar um sítio Web estático, responsivo e acessível para o **Café Aroma**, uma cafetaria artesanal. O sítio procura promover os produtos (cafés de especialidade, pastelaria e refeições ligeiras), disponibilizar informação sobre o estabelecimento, permitir o contacto/reserva através de formulário e apresentar um artigo científico/técnico sobre o impacto da Inteligência Artificial na Acessibilidade Web.

---

## 2. Objetivos por Etapas do Projeto

### Etapa 1: Análise
* **Identificação do Público-Alvo:** Clientes locais, estudantes, trabalhadores remotos e apreciadores de café de especialidade que procuram um espaço agradável ou informações sobre o menu.
* **Levantamento de Requisitos:** 
  * Estruturação de pelo menos 5 páginas estáticas (Página Inicial, Menu/Produtos, Sobre Nós, Contactos/Reservas e Artigo IA).
  * Garantia de conformidade com os padrões de acessibilidade (WCAG 2.2 Nível AA).
  * Conformidade com os critérios SEO para motores de busca.
* **Análise da Concorrência:** Estudo de websites de cafetarias locais para definir pontos fortes e áreas de diferenciação na navegação e usabilidade.

### Etapa 2: Planeamento
* **Arquitetura de Informação:** Definição do *sitemap* e organização hierárquica das páginas e conteúdos.
* **Gestão de Cronograma:** Divisão de tarefas pelas entregas semanais (E1 a E8), garantindo que cada membro assume a responsabilidade de commits e metas específicas.
* **Seleção de Tecnologias:** Uso exclusivo de HTML5 semântico, CSS3 externo, Framework CSS (Bootstrap) e JavaScript nativo/jQuery para componentes interativos, sem dependência de bases de dados ou linguagens de servidor.

### Etapa 3: Desenho (Design)
* **Wireframing:** Criação de *wireframes* de baixa fidelidade para definir o *layout* das páginas principais.
* **Guia de Estilo (Style Guide):**
  * Definição da paleta de cores (tons quentes de café, bege, castanho e contraste adequado para texto/fundo).
  * Escolha tipográfica focada na legibilidade.
* **Design Responsivo (Mobile-First):** Estruturação dos elementos para garantir uma experiência de navegação fluida em ecrãs desde 360 px até ecrãs grandes de desktop.

### Etapa 4: Implementação
* **Desenvolvimento HTML5 & CSS3:** Construção do código válido, utilizando elementos semânticos (`header`, `nav`, `main`, `section`, `article`, `footer`) e apenas um `h1` por página.
* **Formulários e Interatividade:** Criação de um formulário de contacto completo com validação nativa HTML5 e interatividade via JavaScript.
* **Integração de Framework CSS:** Aplicação do Bootstrap para grelhas responsivas e componentes UI.
* **Auditoria e Validação:** Validação contínua através das ferramentas W3C Validator, Lighthouse e WAVE para garantir zero erros e pontuações de acessibilidade/SEO superiores a 90.

### Etapa 5: Marketing & Divulgação
* **Otimização para Motores de Busca (SEO):** Inclusão de meta-tags adequadas (`description`, `viewport`, `Open Graph`), títulos únicos por página e URLs amigáveis.
* **Acessibilidade Universal:** Inclusão de declaração de acessibilidade e garante de navegação por teclado para captar todo o tipo de utilizadores.
* **Publicação e Alojamento:** Publicação do sítio num URL público através do GitHub Pages para consulta e demonstração final.

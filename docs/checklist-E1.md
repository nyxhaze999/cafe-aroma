# Checklist E1 — Café Aroma

Marcar como concluído apenas depois de verificar a evidência.

- [ ] Repositório Git criado e README preenchido com os dois elementos, tema e público-alvo.
- [ ] Pelo menos 3 commits próprios por cada elemento do grupo.
- [ ] Sitemap guardado em `docs/sitemap.md`.
- [ ] Wireframes de baixa fidelidade de 3 páginas guardados em `docs/wireframes.md`.
- [ ] Três páginas HTML com `doctype`, `lang`, `charset`, `viewport` e títulos únicos.
- [ ] Cabeçalhos, listas, tabela, pelo menos 5 imagens com `alt` e ligações internas funcionais.
- [ ] As três páginas validadas no W3C com zero erros.
- [ ] Captura de ecrã do resultado do validador guardada em `docs/`.
- [ ] Tag Git `E1` criada depois de verificar os ficheiros.
- [ ] URL do repositório, hash do commit/tag e checklist submetidos na plataforma da UC.

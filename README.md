# Café Aroma — Projeto de Programação Web

## Identificação do projeto
- **Unidade curricular:** Programação Web — Cliente
- **Tema:** Website de uma cafetaria fictícia
- **Nome do projeto:** Café Aroma
- **Elementos do grupo:** Tiago Bilotti Nunes e Brian Miguel Guerreiro Almeida
- **Público-alvo:** Pessoas da comunidade local, estudantes, trabalhadores e visitantes que procuram café, pequenos-almoços e pastelaria.

## Objetivo
Criar um website estático, acessível e responsivo para apresentar a cafetaria, o seu menu e a sua história.

## Páginas da E1
- `index.html` — página inicial
- `menu.html` — menu e tabela de preços
- `historia.html` — história e galeria

## Estrutura
- `imagens/` — imagens usadas nas páginas
- `docs/` — sitemap, wireframes, checklist e registo de contribuição

## Tecnologias nesta fase
HTML5. As folhas de estilo CSS e as funcionalidades JavaScript serão acrescentadas nas entregas seguintes, de acordo com o enunciado.

## Como visualizar
Abrir `index.html` num navegador. Para validar, enviar cada página para o [Validador HTML do W3C](https://validator.w3.org/).

## Decisões iniciais
- Navegação comum nas três páginas.
- Um título de página único e um único `h1` em cada página.
- Conteúdo em português europeu.
- Texto alternativo descritivo para imagens informativas.

## Contribuições
Preencher `docs/contribuicao-E1.md` com as tarefas reais de cada elemento e manter os commits individuais no Git.
